# Screenshot sources

These PNGs are unmodified captures from the tested KT SHV-E250K installation, added with the owner's request to show real screenshots in the README.

| File | Source |
| --- | --- |
| `note2-fastfetch.png` | Terminal screenshot supplied by the device owner; fastfetch reports the running postmarketOS edge/ARMv7 system and panel1 kernel |
| `note2-sxmo.png` | Sway compositor capture taken during on-device Firefox mobile UI verification; Sxmo's system menu is open |
| `note2-firefox-mobile.png` | Sway compositor capture from the same session after dismissing the menu; Firefox's mobile settings and bottom controls are visible |

The GUI captures are 720×1280 pixels. README display sizes are set in HTML; the original images are retained. The fastfetch host string follows the shared N7105 device tree, rather than identifying the physical Korean carrier variant. Runtime values such as uptime, battery and memory usage describe the moment of capture.
