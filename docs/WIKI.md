# Proposed postmarketOS wiki update

The current [Samsung Galaxy Note II LTE (samsung-t0lte) page](https://wiki.postmarketos.org/wiki/Samsung_Galaxy_Note_II_LTE_(samsung-t0lte)) was reviewed on 2026-09-20. It lists the device as archived, shows kernel 6.16.0, and describes incorrect brightness when the display turns on. Its last-edit footer was 2026-06-23.

The appropriate initial contribution is a scoped **KT SHV-E250K experimental external port** section with reproducible evidence and source links. Do not replace the page's global feature table or kernel version based on one downstream device build, and do not remove its archived warning without the corresponding upstream pmaports work.

[wiki-update-draft.mediawiki](wiki-update-draft.mediawiki) contains an original, paste-ready draft. It has **not been submitted**. At review time, the browser was logged out and the page offered View source rather than edit access. Use an authorized wiki account and follow the site's contribution process to submit it. Creating an account or publishing a wiki edit is a separate action from releasing this repository.

The draft is dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) so it can be incorporated into the wiki under its CC BY-SA terms. This exception applies only to that original draft, not the kernel or the rest of this repository.
